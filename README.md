# Log

매일의 기록을 쌓아 보는 앱 시리즈. 각 앱은 하위 폴더에 독립적으로 들어 있고,
GitHub Pages로 배포됩니다: **https://afflulee.github.io/log/**

| # | 앱 | 폴더 | 주소 |
|---|---|---|---|
| 1 | Weight Log — 몸무게 기록 | [`weight-log/`](weight-log/) | https://afflulee.github.io/log/weight-log/ |

## 구조

```
log/
├── index.html          시리즈 첫 화면 (앱 목록)
├── weight-log/         Log #1
└── .github/workflows/  main에 푸시하면 자동 배포
```

새 앱을 추가할 때: 폴더를 만들고 `index.html`의 목록에 한 줄 추가.

## 휴대폰에 설치

안드로이드 크롬에서 앱 주소를 열고 메뉴(⋮) → **앱 설치** (또는 홈 화면에 추가).
기록은 각 앱 주소의 브라우저 저장소에 보관되므로 주소를 바꾸지 말고, 가끔 앱의 내보내기로 백업하세요.
