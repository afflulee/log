# Weight Log

**Log 시리즈 #1** — 몸무게를 기록하고 그래프로 보는 웹앱(PWA).

주소: **https://afflulee.github.io/log/weight-log/**

이 폴더는 독립적입니다. 다른 폴더를 참조하지 않고 모든 경로가 상대경로입니다.

## 기능

- **그래프**: 주간 / 월간 / 년간 / 전체 — 달력 기준(주는 월요일 시작), `‹ ›`로 이전 기간 이동
  - 평균·최저·최고·변화 요약, 목표 체중 점선, 터치/호버 시 값 표시
- **직접 입력**: 체중, 날짜·시간, 메모 (기록 눌러서 수정·삭제)
- **사진 찍기**: 체중계를 찍으면 숫자를 읽어 자동 입력 (저장 전에 확인·수정)
- **앨범에서**: 예전에 찍어둔 체중계 사진 여러 장을 한 번에 — 사진의 **촬영 날짜(EXIF)**로 기록
- **백업**: JSON / CSV 내보내기, 가져오기 (중복은 자동으로 건너뜀)
- 오프라인 동작, 홈 화면에 추가 가능, 다크 모드

## 사진 인식 방식

| 방식 | 설정 | 정확도 |
|---|---|---|
| Claude API (권장) | 설정 → Claude API 키 입력 | 체중계 LCD(7-세그먼트) 숫자도 잘 읽음, lb 표시는 kg로 변환 |
| 기기 OCR (Tesseract.js) | 키 없을 때 자동 사용 | 낮음 — 결과를 꼭 확인 |

API 키는 이 기기의 브라우저 저장소에만 보관되고, 사진은 인식용으로만 전송되며 저장하지 않습니다.

## 데이터 저장

기록은 브라우저 `localStorage`(`weightlog.*` 키)에 저장됩니다.
브라우저 데이터를 지우면 사라지므로 가끔 **설정 → JSON 내보내기**로 백업하세요.

## 실행

빌드 없음. 정적 파일 서버로 이 폴더를 열면 됩니다.

```bash
cd weight-log
python3 -m http.server 8000
# http://localhost:8000
```

`main`에 푸시하면 GitHub Pages로 자동 배포됩니다.
휴대폰에서는 위 주소를 크롬으로 열고 메뉴(⋮) → **앱 설치**.

## 구조

```
weight-log/
├── index.html              화면
├── css/style.css           스타일 (라이트/다크)
├── js/
│   ├── app.js              화면 로직, 기간 계산, 입력/백업
│   ├── store.js            기록·설정 저장 (localStorage)
│   ├── chart.js            SVG 그래프 (외부 라이브러리 없음)
│   ├── ocr.js              사진 → 체중 인식 (Claude / Tesseract)
│   └── exif.js             사진 촬영 날짜 읽기
├── manifest.webmanifest    PWA 설정
├── sw.js                   오프라인 캐시 (파일 수정 시 VERSION 올리기)
└── icons/
```

Log 시리즈의 다음 앱도 `log/` 아래에 같은 구조(`store` / `chart` / 입력)로 만들 수 있게 나눠 두었습니다.
